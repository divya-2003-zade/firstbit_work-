## 🚀 Project

### Player Management System

A console-based C project that manages player records.

**Features:**

* Add Player
* Display Players
* Search Player
* Update Player
* Delete Player
* Sort Players
* Manage player information using structures
* Dynamic memory allocation

**Player information includes:**

* Jersey Number
* Player Name
* Runs
* Wickets
* Matches Played
