## Assignment 5 — Pattern Programs

### 📌 Description

This assignment focuses on **pattern printing in C** using nested loops. The programs generate different patterns using stars (`*`) and numbers.

The assignment covers solid, right-angled, inverted, pyramid, Floyd's triangle, diamond-style, and hollow patterns.

### 📝 Programs Covered

| No. | Program                             | Concepts                                     |
| --- | ----------------------------------- | -------------------------------------------- |
| 1   | Solid Square Pattern                | Nested loops, rows and columns               |
| 2   | Right-Angled Triangle Pattern       | Nested loops, increasing columns             |
| 3   | Inverted Right-Angled Triangle      | Nested loops, decreasing columns             |
| 4   | Pyramid Pattern                     | Nested loops, pattern generation             |
| 5   | Inverted Pyramid Pattern            | Nested loops, decreasing pattern             |
| 6   | Half Pyramid Using Numbers          | Nested loops, number patterns                |
| 7   | Floyd's Triangle                    | Nested loops, sequential numbers             |
| 8   | Diamond-Style Star Pattern          | Nested loops, increasing and decreasing rows |
| 9   | Hollow Square Pattern               | Nested loops, boundary conditions            |
| 10  | Hollow Square with Diagonal Pattern | Nested loops, conditional pattern logic      |

### 💡 Concepts Practiced

* Nested `for` loops
* Rows and columns
* Increasing and decreasing patterns
* Star (`*`) patterns
* Number patterns
* Sequential number generation
* Boundary conditions
* Conditional statements inside loops
* Hollow patterns
* Pattern-based problem solving
