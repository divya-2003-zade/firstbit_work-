## Assignment 4 — Range Programs and Menu-Driven Program

### 📌 Description

This assignment focuses on working with **ranges of numbers**, identifying special numbers, and developing a **menu-driven program** using conditional statements.

The programs practice checking Armstrong, Prime, Perfect, and Strong numbers within a given range. The final program combines multiple number operations into a single menu-driven application.

### 📝 Programs Covered

| No. | Program                          | Concepts                                                     |
| --- | -------------------------------- | ------------------------------------------------------------ |
| 1   | Print Armstrong Numbers in Range | Loops, digit extraction, Armstrong number logic              |
| 2   | Print Prime Numbers in Range     | Loops, divisibility, prime number logic                      |
| 3   | Print Perfect Numbers in Range   | Loops, factors, sum of factors                               |
| 4   | Print Strong Numbers in Range    | Loops, factorial, digit extraction                           |
| 5   | Menu-Driven Number Operations    | Menu, switch/case, conditional statements, number operations |

### 🔹 Menu-Driven Operations

The menu-driven program allows the user to select an operation:

1. Check whether a number is **Even or Odd**
2. Check whether a number is **Prime or Not**
3. Check whether a number is **Palindrome or Not**
4. Check whether a number is **Positive, Negative, or Zero**
5. **Reverse** a number
6. Find the **Sum of Digits**
