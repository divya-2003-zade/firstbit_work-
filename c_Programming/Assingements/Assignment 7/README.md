## Assignment 7 — Functions Using Pointers

### 📌 Description

This assignment focuses on using **pointers with user-defined functions**.

All **Type 3 functions — with parameter and without return type** are implemented using pointers. The programs practice passing addresses to functions and modifying or working with values through pointers.

### 📝 Program Covered

* Convert all **Type 3 functions (with parameter, without return type)** into pointer-based functions.

### 💡 Concepts Practiced

* Pointers in C
* Address operator (`&`)
* Dereference operator (`*`)
* Passing addresses to functions
* Pointer parameters
* Modifying values through pointers
* Functions with parameters
* Functions without return type
* Call by address
