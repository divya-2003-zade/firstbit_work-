## 🟢 Assignment 0 — C Programming Basics

### 📌 Description

Assignment 0 focuses on the **fundamentals of C programming** using hardcoded input values.

The programs cover basic arithmetic operations, mathematical formulas, unit conversion, swapping values, and calculating averages and percentages.

> **Note:** All input values are hardcoded as required in the assignment.
> Example:
>
> ```c
> int no = 10;
> ```

### 🔢 Programs Included

#### 1. Addition of Two Integers

Adds two hardcoded integer values and displays the result.

#### 2. Area of a Circle

Calculates the area of a circle using its radius.

#### 3. Celsius to Fahrenheit

Converts a temperature from Celsius to Fahrenheit using the given formula.

#### 4. Swap Two Numbers

Swaps two numbers using a **temporary third variable**.

#### 5. Average of Five Numbers

Takes five hardcoded numbers, calculates their total, and finds their average.

#### 6. Square and Cube

Calculates the square and cube of a given number.

#### 7. Minutes to Hours

Converts total minutes into:

* Hours
* Remaining minutes

This program uses **integer division** and the **modulus (`%`) operator**.

#### 8. Perimeter of Rectangle

Calculates the perimeter using the length and width of a rectangle.

#### 9. Area of Triangle

Calculates the area using the base and height of a triangle.

#### 10. Total Marks and Percentage

Calculates:

* Total marks obtained in five subjects
* Percentage
