## Assignment 6 — Functions

### 📌 Description

This assignment focuses on converting previously developed C programs into **user-defined functions**.

The programs from earlier assignments are reorganized using different types of functions based on whether they **accept parameters** and whether they **return a value**.

### 📝 Programs Covered

#### 1. Assignment 1 Programs

Convert the programs from **Assignment 1** into functions using all **four types of functions**:

1. Without parameter and without return value
2. With parameter and without return value
3. Without parameter and with return value
4. With parameter and with return value

---

#### 2. Assignment 3 Programs

Convert the programs from **Assignment 3** into functions using all **four types of functions**.

**Note:** Range programs are excluded from this conversion.

The **range programs** are converted using these two types:

1. Without parameter and without return value
2. With parameter and without return value

---

#### 3. Assignment 4 Programs

Convert the programs from **Assignment 4** using these two types of functions:

1. Without parameter and without return value
2. With parameter and without return value

### 💡 Four Types of Functions in C

| Type   | Parameter | Return Value |
| ------ | --------- | ------------ |
| Type 1 | No        | No           |
| Type 2 | Yes       | No           |
| Type 3 | No        | Yes          |
| Type 4 | Yes       | Yes          |
